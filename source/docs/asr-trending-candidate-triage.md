# Trending local ASR candidates

This note triages the candidates in the supplied Hugging Face ASR list for Sniptype. It is a research snapshot, not a benchmark. No weights were downloaded. Claims below are from the model owner card or owner runtime/repository; an owner card's leaderboard number is not treated as a cross-model comparison unless the dataset and protocol match.

## Decision

Keep Parakeet Q8 as the default, Qwen3-ASR 1.7B Q8 as the accuracy profile, and Nemotron 3.5 Q8 as the streaming profile. The one new candidate that earns a controlled local trial is **Qwen3-ASR 0.6B**: the existing transcribe.cpp path provides an 811 MB Q8 build, 4.1–4.6x CPU realtime on Ryzen 4750U, and 2.11% LibriSpeech test-clean WER. It is slower and less accurate than Parakeet on that same runtime test, so this is a challenger benchmark rather than a replacement decision. VibeVoice's CPU engineering is attractive, but its owner's published MLC-PT WER is 24.87%; it does not get an integration slot before a same-corpus quality result overturns that warning. Voxtral is the strongest future streaming-quality candidate, but its BF16/GPU-oriented runtime is unsuitable for the current desktop baseline.

## Local screening benchmark (2026-08-27)

Whisper large-v3-turbo Q8 does **not** earn a selectable profile. On the same five short synthetic pt-BR, en-US, and code-switching recordings, it tied Parakeet's 5/31 word errors while taking about 5.7x as long per warm clip. Both Qwen sizes produced fewer errors. Whisper also consumed about 138 MiB more Vulkan memory than Parakeet, so it supplied no compensating footprint advantage over the current default.

| Q8 model | Word errors / WER | Median warm clip | Aggregate realtime | Load | Private bytes after load | Vulkan memory delta |
|---|---:|---:|---:|---:|---:|---:|
| Parakeet TDT 0.6B v3 | 5/31 (16.13%) | 34 ms | 76.86x | 1.19 s | 1.33 GiB | 707 MiB |
| Qwen3-ASR 0.6B | 4/31 (12.90%) | 68 ms | 40.97x | 1.73 s | 1.79 GiB | 1.18 GiB |
| Qwen3-ASR 1.7B | 3/31 (9.68%) | 209 ms | 18.01x | 3.81 s | 3.57 GiB | 2.95 GiB |
| Whisper large-v3-turbo | 5/31 (16.13%) | 198 ms | 16.57x | 1.78 s | 1.40 GiB | 845 MiB |

Protocol: Windows 11, Intel Core i7-13620H, RTX 4060 Laptop GPU via Vulkan, transcribe.cpp native 0.1.3, one isolated process per model, one scored pass plus three warm timing passes per clip. The five existing TTS recordings total only 31 normalized reference words. This is a directional product screen, not a publishable quality benchmark: it does not represent microphone noise, accents, long dictation, names/URLs, or natural code-switching. A real-headset corpus could reopen the decision only if Whisper materially beats both Qwen and Parakeet on error quality, not merely aggregate WER.

## Duplicate and conversion classification

- `handy-computer/nemotron-3.5-asr-streaming-0.6b-gguf` and `handy-computer/parakeet-tdt-0.6b-v3-gguf` are GGUF conversions of the NVIDIA models, not distinct model families. Evaluate the converter/runtime checksum and license separately, but count quality against the NVIDIA parent.
- `Systran/faster-whisper-*` entries are CTranslate2 conversions of OpenAI Whisper checkpoints. They are materially different runtimes and memory profiles, not new trained models.
- `Qwen3-ASR-1.7B-hf` and the original Qwen3-ASR-1.7B checkpoint represent the same family in different Transformers packaging. The 0.6B entry is a distinct size variant. `Qwen3-ForcedAligner` is a separate post-processing model.
- The supplied list contains no Gemma 4 entry; Gemma remains a separate audio-understanding/ASR candidate and should not be inferred to outrank these task-specialized models.

## What is still missing

The owner cards do not provide a common Portuguese (Brazil) test set, identical decoding settings, peak RSS, cold-start latency, or streaming partial-result latency across this list. FLEURS, LibriSpeech, Common Voice and HF leaderboard figures must stay in separate rows until we run one corpus and protocol. The next meaningful gate is a local matrix with pt-BR, en-US, code-switching, names/URLs, 5–30 second clips, cold and warm latency, peak RSS, and real-time factor on the supported Windows and Apple Silicon machines.

## Shortlist and exclusions

1. **Qwen3-ASR-0.6B Q8 and Q4_K_M** — first new benchmark, against the current Parakeet and Qwen 1.7B profiles on one pt-BR/en-US/code-switching corpus.
2. **Whisper large-v3-turbo Q8 through transcribe.cpp** — benchmark on the existing provider, but do not expose it until it proves a material corpus win.
3. **Voxtral Mini 4B Realtime** — GPU or future quantized-runtime watchlist; its Portuguese streaming numbers merit attention.
4. **Granite Speech 4.1 2B Plus** — meeting/transcript feature research only; its lack of punctuation/capitalization is a poor fit for short dictation.
5. **Canary-1B-v2** — multilingual batch research after a practical portable CPU path exists.

Exclude from the immediate product path: VibeVoice because its published Portuguese accuracy is too weak; Voxtral Mini 4B because of footprint/runtime mismatch; Qwen ForcedAligner as a primary ASR model because it is alignment-only; GGUF/conversion entries as duplicate family scores; and all large Whisper checkpoints as default CPU providers until the target hardware matrix proves acceptable latency.
